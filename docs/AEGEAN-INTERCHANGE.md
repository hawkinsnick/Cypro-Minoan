# Aegean Epigraphy Interchange v0.1 — Cypro-Minoan adapter

Shared concepts: records/identifiers, assertions, provenance, uncertainty, rights, source lineage, physical loci, representations, occurrences and hypotheses.

Explicit non-equivalences: CMSIGN is not AB; CM classifications are not cross-script categories; CM segmentation does not inherit Linear A source-word objects; Unicode is not palaeographic identity; graphical similarity does not propagate phonetic value. Native repositories remain authoritative and independently versioned.
