# Cross-project roadmap

Keep Cypro-Minoan and Linear A in separate repositories and release histories.

1. Harmonize only decipherment-neutral interfaces now.
2. Extract shared validators only after both projects independently demonstrate the same need.
3. Create a future `aegean-epigraphy-core` containing neutral code/schemas, not corpus data.
4. Add comparative algorithms through corpus adapters.
5. Add Linear B only after the neutral core survives both undeciphered corpora.

No shared-core requirement may force this corpus to invent an observation or segmentation absent from Cypro-Minoan evidence.
