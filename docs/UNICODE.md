# Unicode Policy

Cypro-Minoan entered the Unicode Standard in version 14.0. The current block is U+12F90–U+12FFF with 99 encoded characters. Unicode states that the repertoire is largely based on Olivier 2007, covers CM1/CM2/CM3, and does not cover CM0.

Therefore:
1. Unicode code points are useful interoperable representations.
2. A Unicode character is not automatically identical to a project palaeographic sign concept.
3. Unencoded signs/variants must remain representable.
4. Unicode character names must not be interpreted as deciphered phonetic values.
5. Mappings to Unicode must be sourceable and revisable.

Source: Unicode Standard, §8.4 Cypro-Minoan.
