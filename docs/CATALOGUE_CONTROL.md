# Catalogue control — v1.2.0

Catalogue completeness and content completeness are separate metrics. `catalogues/master.json` registers numbered historical/addendum slots without implying that the project owns a transcription, image, or complete object record. Each entry names its authority layer and verification status. Source-defined corpus snapshots are preserved in `catalogues/snapshots.json`; they must not be collapsed into a single timeless corpus total.
