# Architecture 4.0 — comprehensive/reproducible research platform

4.0 preserves the 3.0 evidence→witness→research→interchange dependency direction and adds reproducibility as a first-class layer.

## Research chain
result → experiment specification/gate → parameters/null controls → dataset snapshot → corpus policy/sensitivity state → occurrence/witness → physical locus/object → assertion → source → source lineage → rights.

Every link may be incomplete; incompleteness is represented, not inferred away.

## Shared-core boundary
The future neutral Aegean core may contain only abstractions already required with the same semantics by Linear A and Cypro-Minoan: provenance-bearing assertions, uncertainty, rights, source lineage, dataset snapshots, experiment gates, claim registry and interchange validation. Native segmentation, catalogue systems, sign identities, phonetics and morphology stay outside.

## Stability
Aegean Epigraphy Interchange v0.1 and Research API v1 remain stable. New script-specific capabilities enter extensions until cross-project evidence justifies promotion.

## Non-goals
4.0 does not claim a complete modern corpus, complete exact-siglum reconciliation, complete transcription/occurrence coverage, a complete variant inventory, decipherment, language identification, phonetic proof or corpus-wide statistical validity where gates remain blocked.
